## Problem: Two Sum
(Easy)

**Link:** https://leetcode.com/problems/two-sum/

### Approach
Use a nested loop to check each pair of values. This is simple and easy to test locally in C before submitting to LeetCode.

### Complexity
- Time: O(n^2)
- Space: O(1)

### Notes
This is the basic brute-force version. A more efficient approach would use a hash map, but this version is easier to understand and works well for learning.
