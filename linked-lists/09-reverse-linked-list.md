## Problem: Reverse Linked List
(Easy)

**Link:** https://leetcode.com/problems/reverse-linked-list/

### Approach
Iterate through the linked list while changing each node's next pointer to the previous node. This reorders the structure in place.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
This is a classic pointer-rewiring problem and is a good example of how to reverse a structure without extra memory.
